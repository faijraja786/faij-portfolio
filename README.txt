FAIJ PORTFOLIO

1. Extract this ZIP file.
2. Open the folder and double-click index.html to preview the website.
3. Edit index.html to replace hello@example.com with your real contact email.
4. Replace the sample project concepts with projects you have actually built.
5. Edit the text in index.html to add your real links and details.

The website uses HTML, CSS and JavaScript. Google Fonts load online; the site still works with fallback fonts offline.
